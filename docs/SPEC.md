# 园区水量漏损排查 · 字段与计算

本项目使用确定性模拟业务数据。所有时间均以业务台账指定粒度解析。

## 记录与单位

`flow_register.json` 是按水表和时点的整数升累计计数器，版本同效冲突隔离。达到末端后的合理反跳按计数器上界换算，换表与长失联不能猜测增量。`quiet_hour_rules.json` 按分区给定半开窗口，按区间重叠分钟进行有理数分摊。时间是同一值班周内的营运分钟。

历史基线隔离计划冲洗、生产夜班与覆盖不足。按压力平方根进行流量校正。画像模型对不同营业类型用稳健缩放进行 L1 距离和 k-medoids 聚类，以设备编号稳定消歧。簇编号的评估先按混淆矩阵求一对一最大重合。

## 巡检动作

结合经验尾概率、离群距离与持续周界来判断是否出单。关阀后的持续过水可直接派给有双资质的小组。巡检容量默认 6。组间比较需考虑区间通行、班内剩余分钟与资质。复测数据只有结案后的事实，作为事后校验独立处理，不参与生成待查清单。

## 下一班预警线

每个用水簇各有一条净余流预警线，单位升每分钟，默认取策略最小异常净余流。交班时用已结案复测回放重新标定，判定口径与当班筛查一致：

- 结案时点不晚于交班时点的回执才进入回放；迟到的复测记录只能在下一班生效，本班既不按确认也不按排除计数。
- 排除样本给出下界，确认样本给出上界；在两者之间取最靠近下界的一条线，即放低门槛少漏、但不重复误报。上界低于下界时不改线。
- 缺测夜窗没有可用信号，相关回执记为「缺测不判」，既不确认也不排除，也不能当作正常用水。
- 放低门槛会增加听漏工单。名额不足以覆盖全部下调时，按漏判数、确认样本数排序逐个启用，其余簇本班继续沿用。
- 每张表采用哪条线、派次依据和预警线版本同版记录；改线依据逐簇留痕。

同一批回执重跑按指令内容（表号、任务、班组、开始分钟、预警线及版本）生成稳定工单号，已发台账按工单号去重，重复提交只命中既有工单，不会新开。
